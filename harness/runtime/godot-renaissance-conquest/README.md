# Renaissance Conquest Godot Runtime

Godot-first prototype for the Renaissance Italy isekai conquest concept.

Open this folder in Godot:

```bash
godot --path harness/runtime/godot-renaissance-conquest
```

Run the smoke test:

```bash
godot --headless --path harness/runtime/godot-renaissance-conquest --script res://scripts/tools/smoke.gd
```

The initial scene is a native Control prototype, not a final art pass.
