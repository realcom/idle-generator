# Ninja2 Survival Visual Red Moon E

## Intent

현재 수호자 에셋을 유지한 채, 닌자/요괴/붉은 달 판타지를 가장 강하게 밀어본 고대비 색채 실험 시안.

## Art Anchor

- 주인공은 복면 닌자가 아니라 기존 등불 수호자다.
- 적은 요괴 분위기를 더하지만 반복 가능한 2D 실루엣으로 유지한다.
- 붉은 달, 검은 대나무, 금색 등불, 청록 영혼불이 핵심 색이다.

## Composition Rules

- 화면 전체를 더 위험하고 어둡게 보이게 하되, 주인공 등불 원은 명확히 남긴다.
- 붉은 경고 glyph와 붉은 slash crescent를 주요 그래픽 신호로 쓴다.
- 픽업 색은 기존 자원 색과 충돌하지 않게 유지한다.

## UI Direction

- UI는 금색/검정 프레임으로 유지하되, 붉은 배경에 묻히지 않게 대비를 강화한다.
- 실제 구현에서는 생성 이미지의 장식 텍스트/부적 글자는 제거하거나 asset ornament로만 쓴다.

## Implementation Notes

- 기본 숲 전투보다 마케팅/챕터2/이벤트맵 방향에 잘 맞는다.
- 런타임으로 옮길 때는 전 화면 팔레트를 바꾸기보다 붉은 달 맵 스킨, 붉은 경고 VFX, 요괴 적 세트로 제한하는 것이 안전하다.
- 현재 cozy sanctuary 정체성과 거리가 있으므로 selected 전에 디자인 리뷰가 필요하다.
