# Dokkaebi Survivor Creative Brief

작성일: 2026-06-22
상태: planning draft

## One Line

`도깨비의 세계` IP의 해일/몽련을 전면에 세운 조선 민담풍 survival RPG.

탕탕특공대식 즉시 전투 재미를 첫 화면에서 주고, Zombie Waves식 장기 매출 구조인 영웅, 무기, 동료, 장비, 이벤트, 거점 성장을 도깨비/요귀/수련 문법으로 치환한다.

## Product Shape

핵심 경험은 "밤마다 몰려오는 요귀 무리를 정화하고, 낮에는 수련당과 마을을 키워 다시 더 깊은 원정에 나간다"이다.

- 전투: portrait one-hand survival run, 자동 공격, EXP 픽업, 3카드 스킬 선택, 보스 출현.
- 메타: 수련당/문파 거점, 방치 보상, 장비/법기/부적 강화, 동료/식신 성장.
- IP 앵커: 해일/몽련은 메인 영웅이자 매출형 캐릭터/스킨/전용 무기 축.
- 세계 톤: 무겁고 잔혹한 좀비물이 아니라, 선명한 조선 민담/무협풍 인물과 익살 있는 요괴가 공존하는 모바일 RPG 톤.

## Reference Interpretation

현재 확인한 NPC 리소스 PDF는 다음 기준을 준다.

- 포트레이트: 웹툰풍 반실사, 굵은 외곽/명암, 표정과 인상이 강함.
- SD/NPC: 작은 픽셀 캐릭터, 거점/대화/마을용 가독성에 적합.
- 인물 폭: 남녀노소, 도적, 병사, 상인, 장인, 아이, 사냥꾼, 기이한 술사까지 넓음.
- 비용 구조: 모든 NPC에 포트레이트가 필요한 구조가 아니다. 중요 NPC만 포트레이트+SD, 일반 NPC는 SD 단독으로 충분하다.
- 전투 주역 주의: 기존 NPC SD는 작고 얌전하므로 해일/몽련의 전투 SD는 더 크게, 색이 강하게, 실루엣이 단순하게 별도 제작해야 한다.

## MVP Slice

첫 플레이어블은 7일짜리 세로 슬라이스로 제한한다.

| Area | Scope |
| --- | --- |
| Heroes | 해일, 몽련 2명. 실제 구현 1명 우선, 두 번째는 선택/잠금/미리보기 가능 |
| Combat | 75-180초 survival run, 1개 맵, 1개 보스, 3카드 레벨업 |
| Enemies | 일반 요귀 4종, 엘리트 2종, 보스 1종 |
| Skills | 시작 스킬 1개, 선택 풀 6개, 후반 후보 6개 |
| Meta | 수련당 홈, 방치 보상, 장비 6슬롯, 법기/부적/동료 초안 |
| Economy | 골드, 영혼불, 부적 조각, 프리미엄 재화 |
| Live Ops Seed | 출석, 성장 펀드, 시즌 패스, 보스 랭킹 문서화만 |

## Combat Fantasy

### 해일

역할: 수류/검기/파도 기반의 초반 주인공.

- 기본 공격: 짧은 수류 베기 또는 물방울 투사체.
- 초반 선택: 파도 밀어내기, 물소용돌이, 수호 물결.
- 상위 선택: 해일 파도, 용오름, 물거울 분신.
- 색: 청색/남색/백색 포말. 전투 화면에서는 exp blue와 겹치지 않게 더 깊은 청록/흰 포말을 사용한다.

### 몽련

역할: 도깨비 술법/제어/꿈/연꽃 계열의 전략형 영웅.

- 기본 공격: 도깨비불 탄환 또는 부적 투척.
- 초반 선택: 몽환 연기, 연꽃 결계, 도깨비불 추적탄.
- 상위 선택: 꿈결 속박, 흑련 폭발, 요귀 봉인진.
- 색: 보라, 청록, 옅은 금. 화면 정리용 궁극은 보라/흰 빛 대비를 강하게 둔다.

## Enemy Families

초기 적은 "많이 몰려와도 읽히는 실루엣"이 우선이다.

| Family | Runtime Role | Visual Note |
| --- | --- | --- |
| 잡귀 | 가장 약한 추격형 | 작은 검은 몸, 밝은 눈, 2-3프레임 이동 |
| 도깨비 하수 | 중간 체력 근접 | 뿔/몽둥이 실루엣, 붉은/주황 포인트 |
| 망령 | 느린 관통/부유형 | 흐린 청록, 낮은 채도, 투명 꼬리 |
| 산도적/마을 적대 NPC | 인간형 변주 | 기존 NPC/도적 SD 톤 활용 가능 |
| 부적술사 | 원거리 탄막 | 모자/부적/긴 소매 실루엣 |
| 보스 요괴 | 큰 체력/패턴 | 화면에서 2-3배 크기, 선명한 공격 전조 |

## Visual Contract

- 포트레이트와 SD를 같은 캐릭터로 묶되, 런타임 가독성은 SD가 이긴다.
- 전투 캐릭터는 NPC보다 머리/무기/VFX 포인트를 크게 둔다.
- 요괴 무리는 디테일보다 색, 외곽, 이동 리듬으로 구분한다.
- 배경은 넓고 낮은 디테일이어야 한다. 작은 캐릭터와 탄막을 삼키는 고명도 복잡 배경은 피한다.
- UI는 조선풍 종이/목재/먹선 질감을 쓰되, 전투 HUD는 Zombie Waves처럼 반복 플레이에 방해되지 않게 얇고 기능적으로 둔다.

## First 72 Hours

1. 해일/몽련 캐릭터 바이블 정리: 공식 이미지, 성격, 무기, 색, 금지 변형.
2. `dokkaebi` profile/content/design/assets 폴더 생성 기준 확정.
3. `ninja2` survival run 레벨업/스킬 풀을 도깨비 테마로 복제할 목록 작성.
4. 전투 가독성용 해일 SD, 일반 잡귀, 첫 보스, 밤 숲 배경의 asset dry-run 준비.
5. D1 playable goal: 75초 전투, 1회 이상 레벨업 선택, 보스 등장, 결과 보상.

## Open Questions

- 해일/몽련의 공식 원화와 사용 가능한 파생 범위는 어디까지인가?
- AI 생성 에셋을 상업 빌드에 넣어도 되는지, 내부 검수/라이선스 문구가 필요한가?
- 도깨비의 세계 원작 톤에서 피해야 하는 표현은 무엇인가?
- 해일/몽련 외에 첫 시즌 매출 캐릭터 후보가 있는가?
- 기존 NPC SD를 실제 런타임에 넣을 수 있는 원본 파일 접근이 가능한가, 아니면 스타일 참조로만 쓸 것인가?
