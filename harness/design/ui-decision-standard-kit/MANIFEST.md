# Manifest

Package: `ui-decision-standard-kit`

Version: `2026-06-16`

Purpose: portable UI decision rules and starter templates for concept-to-Phaser
implementation work.

## Files

- `README.md`: quick start and package overview.
- `UI_DECISION_STANDARD.md`: canonical decision rules.
- `PHASER_HANDOFF.md`: Phaser-specific handoff checklist.
- `AGENT_BRIEF.md`: copy-pasteable instructions for another AI or designer.
- `SKILL_INTEGRATION.md`: exact hooks to embed shared UI foundation rules into skills and harness docs.
- `SLACK_SHARE.md`: concise Korean share text for Slack or messenger handoff.
- `templates/ui-system-inventory.template.yaml`: project UI system audit.
- `templates/button-system.template.yaml`: shared button rules.
- `templates/modal-system.template.yaml`: shared modal/dialog rules.
- `templates/color-tokens.template.yaml`: semantic color rules.
- `templates/design-registry.template.yaml`: concept status registry.
- `templates/concept-note.template.md`: concept note format.
- `templates/art-direction.template.yaml`: visual identity contract.
- `templates/layout-tokens.template.yaml`: layout and responsive tokens.
- `templates/component-blueprints.template.yaml`: semantic section/component contract.
- `templates/component-skins.template.yaml`: component-to-skin mapping.
- `templates/asset-plan.template.yaml`: generated/reused asset contract.
- `templates/motion-juice.template.yaml`: motion and feedback rules.
- `templates/critique-rubric.template.yaml`: review gate.
- `templates/phaser-ui-spec.template.yaml`: Phaser runtime implementation spec.

## External Use

Copy this folder into another project, replace `<game>`, `<concept-id>`,
`<surface>`, and `<ComponentName>` placeholders, then follow the pipeline in
`README.md`.
