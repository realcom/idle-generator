# Taskstonebar

`Taskstonebar`는 `/Users/yangjinhwan/Downloads/taskstone (1)/`의 Task Stone 프로토타입 감성을 하네스 콘텐츠로 옮기는 첫 수직 슬라이스다.

핵심 방향:

- 작업표시줄 하단 스트립 위에서 작은 픽셀 영웅이 자동 전투한다.
- 돌/광석은 머지 보드와 큐브 제련의 성장 재료가 된다.
- 오프라인은 골드/경험치만 지급하고, 상자/촉매/고등급 광석은 온라인 체류 보상으로 둔다.
- UI는 갈색 9-slice 패널, 금색 타이틀, 어두운 내부 패널, 32px 픽셀 아이콘을 기준으로 한다.

현재 범위는 컴파일 가능한 MVP 데이터와 에셋 레지스트리다. 2026-06-29 기준 카탈로그의 MVP 본선 세트는 `review` 상태로 승격했고, `approved/` 물리 이동은 Godot QA와 에셋 라이선스 확인 이후로 둔다. 실제 Electron/Phaser 작업표시줄 런타임 이식은 다음 단계로 분리한다.
